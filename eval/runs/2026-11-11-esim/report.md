# Сравнение: агент «Стратег» и обычный чат с ИИ

**Задача:** учебный бриф «туристические eSIM для мобильного оператора» (только открытые данные), 11.11.2026.
**Способы:**
- **A. Агент** — этот репозиторий, полный процесс с воротами G1–G3 (`projects/esim-travel/`);
- **B. Обычный чат** — та же модель (Claude Opus 5.5) с веб-поиском, без репозитория. Один запрос по `eval/baseline-prompt.md`, без уточнений (`baseline.md`).

Ручной способ (аналитик) не измерялся.

## Итог

| Показатель | A. Агент | B. Обычный чат |
|---|---|---|
| Время по часам | 58 мин (с перерывом сессии, ожиданием ответов на G1–G3 и исправлением багов агента по ходу) | 5,4 мин |
| Участие человека | 3 решения на воротах + 1 ответ о данных | 0 |
| Стоимость | ≈ $7.3 (по хуку; включает отладку самого агента в прогоне) | $1.31 |
| Источников | 13 в реестре, у каждого надёжность | 13 поисков, 14 загрузок |
| **Строк с числами, у которых есть ссылка на источник** | **28 из 29 (97%)** | **10 из 35 (29%)** |
| Проверка 20 случайных строк со ссылками: подтверждено полностью | 17 (85%) | 12 (60%) |
| — частично | 3 | 6 |
| — не подтверждено | 0 | 0 |
| — проверить нельзя (источник недоступен) | 0 | 2 |
| Рубрика, слепая оценка Haiku (из 36) | 35 | 27 |
| Рубрика, слепая оценка Opus (из 36) | 34 | 27 |
| Какой документ предпочли оценщики | оба — A | — |

## Что это значит
- **Доверие.** Главное отличие — покрытие ссылками. Если ссылка есть, оба способа редко ошибаются: неподтверждённых строк нет ни у одного. Но у обычного чата 71% чисел вообще не имеют источника, и проверить их нельзя. У агента каждое число прослеживается до реестра с типом утверждения.
- **Полнота стратегии.** По оценкам обоих оценщиков, у обычного чата не хватает:
  - «что должно быть правдой» для вариантов, кроме «оставить как есть»;
  - количественного прогноза для «оставить как есть»;
  - экономики;
  - сопоставления обещаний с продуктом.

  Его ключевое сообщение «по цене местной симки» противоречит его же ценовой политике (оценщик Opus). Рекомендуемый вариант у него почти не прошёл критику.
- **Где обычный чат лучше.** Он в 10 раз быстрее и в 5 раз дешевле, сразу открывается выводом и даёт более числовые критерии пилота. Оба оценщика сняли у агента балл за то, что рекомендация не стоит в первых строках. Исправлено: навык `verify` теперь создаёт `00-summary.md`.
- **Цена качества.** Время агента в основном уходит на сбор с регистрацией источников, две итерации red-team и решения человека на воротах. Стоимость растёт ещё и от длины контекста: прогон шёл в той же сессии, где собирался сам агент. Рекомендация — один проект в одной свежей сессии; продолжение через `/next` это поддерживает.

## Ограничения замера
- Одна задача, один прогон каждого способа. Это иллюстрация, а не статистика.
- Рубрика — собственная рубрика агента (`method/quality-rubric.md`), и шаблоны агента построены под неё. Это даёт агенту преимущество в рубричной оценке. Нейтральнее метрики покрытия ссылками и проверки по источникам.
- Оценщики — модели, а не люди. Обезличивание частичное: формат ссылок [C#] выдаёт способ.
- Проверка по источникам — модель Sonnet с загрузкой страниц, по 20 строк на способ.
- Стоимость агента — верхняя оценка: в прогоне чинились баги самого агента.

## Файлы
- `baseline.md` — ответ обычного чата;
- `blind/doc-1.md`, `blind/doc-2.md`, `blind/key.json` — материалы слепой оценки;
- `sample-*.jsonl`, `sample-*-coverage.json`, `verdicts-*.jsonl` — выборки, покрытие, вердикты проверки;
- `rubric-haiku.json` — оценка Haiku; оценка Opus приведена в таблице выше;
- `cost-baseline.json` — стоимость базового прогона.

python eval/transcript_cost.py <транскрипт.jsonl>
