# Демо-видео «Стратег Фабрики продуктов»

Исходники ролика (mp4, 1280×720, русская озвучка, до 10 минут). У агента нет веб-интерфейса, поэтому видео собрано из «терминальных» сцен: каждая реплика, вывод команды и цифра взяты из реальных материалов, ничего не выдумано.

## Откуда берётся текст в кадре

| Источник | Что это | Как получено |
|---|---|---|
| `data/real.json` | дословные записи двух реальных сессий Claude Code: прогон 16.11.2026 (`/kickoff` … G3, решения D1–D8) и новый чат после перерыва (хук `SessionStart`, проверка правовых новостей) | `python scripts/extract_real.py` читает JSONL из `~/.claude/projects/…` |
| `data/live/*.txt` | вывод read-only команд CLI: `status`, `claim show`, `validate`, `search`, `decision list/check`, `impact S22` (без `--flag`), `cost` | `npm run live` (`src/capture-live.mjs`); дата съёмки в `data/live/stamp.txt` |
| `projects/antispam-2027/` | документы проекта (`outputs/*.md`, `journal.md`) | только чтение |
| озвучка и подписи | единственный авторский текст — фразы в `src/scenario.mjs` (поле `narr`) | — |

Длинное сокращается с «…», переписывать своими словами нельзя. На сценах-реконструкциях и в начале видео стоит плашка «Воспроизведение реального прогона 16–17.11.2026 по записи сессий Claude Code, ускорено», на сценах с живым выводом — «Вывод команды, снят <дата>». Пути вида `C:\Users\…` заменяются на пути от корня репозитория, а перед рендером `build.mjs` проверяет все тексты на `@`, имя пользователя Windows, `C:\Users` и останавливается при находке.

## Пересборка одной командой

Один раз:

```
cd video
npm install
npm run setup          # .venv с edge-tts и imageio-ffmpeg + браузер Chromium для Playwright
```

Затем:

```
npm run video          # озвучка → таймлайн → кадры → out/strateg-demo.mp4 + .srt + 4 кадра в docs/img/
```

Нужен интернет: голос `ru-RU-DmitryNeural` синтезирует сервис Microsoft Edge TTS. Готовые фразы лежат в `cache/voice/` и не озвучиваются повторно. Переменные: `VIDEO_VOICE`, `VIDEO_RATE` (например `+8%`), `VIDEO_FPS`, `VIDEO_PY` (свой python с edge-tts), `VIDEO_DRY=1` (только озвучка и хронометраж), `VIDEO_SHOTS=1` (только скриншоты для PDF).

Обновить живой вывод CLI: `npm run live` (запускает только читающие команды и возвращает `journal.md` из git, потому что `validate` дописывает в него строку).

## Устройство

- `src/scenario.mjs` — сцены: слайды и «терминал» (реплика пользователя, ответ агента, вызов инструмента, команда, вывод, фрагмент документа, вопрос на воротах G1–G3, ускорение). Таблица `SPEAK` задаёт произношение («Claude Code» → «Клод Код», «red-team» → «ред-тим» и т. д.).
- `src/player.html` — страница, которая рисует кадр по времени `renderAt(t)`: печать реплик, постепенный вывод строк, прокрутка вниз. Кадры детерминированы, поэтому звук совпадает с картинкой без записи экрана в реальном времени.
- `src/build.mjs` — озвучка, таймлайн, Playwright, ffmpeg (из `imageio-ffmpeg`), субтитры `.srt`, скриншоты.
- `scripts/extract_session.py` — читаемая выгрузка любой расшифровки сессии (реплики, ответы, вызовы инструментов); `scripts/show_record.py` — одна запись целиком.

Тяжёлые файлы (`out/*.mp4`, `.venv`, `node_modules`, кеш озвучки) в git не попадают; `out/strateg-demo.srt` и скриншоты в `docs/img/` — попадают.
