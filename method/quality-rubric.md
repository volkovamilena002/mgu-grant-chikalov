# Рубрика качества

Каждый критерий оценивается от 0 до 2: 0 — нет, 1 — частично, 2 — да. Порог приёмки — не ниже 1 по каждому критерию и сумма не ниже 75% от максимума.

## Картина ситуации (03)
1. Каждое существенное утверждение имеет ссылку [C#].
2. Факты, гипотезы и прогнозы различимы.
3. Пробелы названы с причиной и опасностью для решения.
4. Противоречия источников названы.

## Варианты (04)
1. Не меньше 3 вариантов, они различаются логикой, а не степенью.
2. Есть «оставить как есть» с реальным прогнозом.
3. У каждого варианта есть «что должно быть правдой».
4. Возражения сильные: сторонник варианта задумается.
5. Сравнение по критериям из брифа.

## Стратегии (05–07)
1. Продуктовая: аудитория и задача, альтернативы, направление, осознанные отказы, экономика.
2. Коммуникационная: барьер, сообщение, подтверждение, роли каналов.
3. Каждое обещание сопоставлено с возможностью продукта.
4. Продуктовая и коммуникационная стратегии согласованы: та же аудитория, нет противоречий.
5. План проверки: ожидаемое изменение, сравнение, срок, нежелательные последствия, критерий решения.
6. Синтетические данные не используются как доказательство.

## Для руководителя
1. Вывод в первых строках.
2. Понятно, что делать завтра.
3. Нет общих мест и воды.
