# Проекты

Каждая задача руководителя продукта — отдельная папка `projects/<slug>/`. Её создаёт `python tools/strat.py init <slug>`.

```
inputs/          исходные материалы, не изменяются (inputs/_md — текстовые версии)
analysis/        воспроизводимые расчёты
interviews/      гайды и обезличенные расшифровки (синтетические — с пометкой)
outputs/         итоговые документы 01–07 и отчёт о прозрачности 00
state.json       стадия, ворота, бриф, открытые вопросы, домены, следующий шаг
sources.jsonl    реестр источников S#
claims.jsonl     реестр утверждений C#
decisions.jsonl  решения D# с ответственными и условиями пересмотра
steps.jsonl      идемпотентные шаги
costs.jsonl      расходы по стадиям и моделям
journal.md       журнал действий (только дописывается)
```

`.active` хранит slug активного проекта.
