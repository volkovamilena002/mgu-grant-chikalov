# Анализ данных

Методика — `method/data-analysis.md`.

1. Файлы — через `strat ingest` (они попадают в `inputs/`). Исходники не меняются.
2. **Разведка.** Короткий скрипт: столбцы, типы, число строк, период, пропуски, дубликаты, явные аномалии. Запиши, что значит каждая метрика. Если непонятно — `strat q add` и спроси человека.
3. **Расчёт.** Большой или многошаговый расчёт делегируй субагенту `data-analyst`. Каждый расчёт — скрипт `projects/<slug>/analysis/NN-<что>.py`:
   - читает из `../inputs/`, печатает результат;
   - нужен `pandas`; если его нет, используй стандартный `csv`.
4. Запусти скрипт, проверь результат на здравый смысл: порядок величин, сумма долей равна 100%, периоды полные.
5. `strat source add --kind analysis --ref projects/<slug>/analysis/NN-…py --title "Расчёт: …" --reliability high`.
6. Результаты → `strat claim add "<число с единицами и периодом>" --type fact --sources S_analysis,S_data`. Интерпретация («отток вырос из-за…») — это `hypothesis`.
7. Ограничения данных (выборка, неполный период, смена методики) запиши в `--note` и в раздел пробелов.
