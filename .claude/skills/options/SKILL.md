# Варианты и возражения

Методика — `method/options-and-objections.md`.

1. По картине ситуации сформулируй 3–5 вариантов, которые различаются логикой. Обязателен «Оставить как есть» с реальным прогнозом. Рассмотри «Закрыть или свернуть направление».
2. Для каждого варианта:
   - суть;
   - основания [C#];
   - «что должно быть правдой»;
   - цена;
   - обратимость.

   Прогнозы записывай в реестр (`--type forecast --depends …`).
3. **Возражения.** Вызови субагента `red-team`, передав путь к черновику `04-options.md` и к `03-situation.md`. Его возражения внеси в разделы «Возражения» как есть. Если с возражением не согласен, добавь ответ ниже, но не удаляй возражение.
4. Сравнительная таблица по критериям из брифа. Без итоговой взвешенной оценки, если человек не задал веса.
5. «Рекомендация агента и что может её изменить»: какой вариант и при каких новых фактах выбор поменяется.
6. `strat validate` — исправь ошибки (нужно не меньше 3 вариантов и раздел «Оставить как есть»).
7. **Ворота G2.** Через вопрос с вариантами (рекомендованный первым) спроси, какой вариант берём. Допустимы комбинация вариантов и «нужно больше данных по X».
   - выбор сделан → `strat gate G2 approve --note "Выбран вариант B: …; причина: …"` → `strat log "…" --kind choice` → `strat stage strategy --next "Разработать стратегии (/strategy)"`;
   - нужны данные → `strat stage collect` и вернись сюда.
