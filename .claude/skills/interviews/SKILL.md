# Интервью и модельные респонденты

Методика — `method/interviews.md`.

## Гайд для реальных интервью
1. По вопросам плана и гипотезам из `03-situation.md` составь гайд на 30–40 минут: вопросы о прошлом поведении, без наводящих формулировок.
2. Сохрани в `projects/<slug>/interviews/guide.md`. Отдельно — короткий текст согласия на участие и запись.

## Разбор реальных интервью
1. Расшифровки — только обезличенные (R1, R2…). Если в тексте есть ФИО, телефоны или e-mail, сначала обезличь и только потом сохраняй. Аудио → `python tools/transcribe.py`.
2. `strat ingest interviews/R1.md --kind interview`.
3. Цитаты → наблюдения → закономерности «k из N респондентов» → гипотезы. Наблюдение «R3 сказал…» — это `fact` со ссылкой, а обобщение — `hypothesis`.

## Модельные респонденты (только гипотезы)
1. Попроси человека согласовать: сколько персон (обычно 3–5) и примерную стоимость. `strat step start synth-<тема>`.
2. Опиши персоны через ситуацию, задачу, альтернативы, ограничения. Обязательно одна персона-скептик и одна «не наша аудитория».
3. Для каждой персоны вызови субагента `synthetic-respondent` с описанием персоны и гайдом. Персоны независимы, их можно запускать параллельно.
4. Каждую расшифровку сохрани в `interviews/synthetic-P<n>.md` с шапкой «СИНТЕТИЧЕСКИЙ РЕСПОНДЕНТ — НЕ РЕАЛЬНЫЙ ПОЛЬЗОВАТЕЛЬ», затем `strat ingest … --kind synthetic`.
5. Утверждения — только `--type synthetic`. Сведи их в список гипотез и для каждой предложи способ проверки на реальных людях или данных.
6. `strat step done synth-<тема> --result "…"`.

Нельзя: проценты и доли по синтетике, слова «подтверждено» и «доказано», смешивание с реальными интервью в одной таблице без явной пометки.
