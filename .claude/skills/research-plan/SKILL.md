# План исследования

Методика — `method/research-planning.md`.

1. Перечитай `outputs/01-brief.md`. Запиши 2–4 правдоподобных ответа на вопрос брифа: это будущие черновые варианты.
2. Для каждого ответа выпиши, что должно быть правдой. Отсюда ключевые вопросы R1…Rn.
3. Оцени каждый вопрос по влиянию, неопределённости и стоимости. Оставь 5–10 вопросов с наибольшим приоритетом.
4. Для каждого вопроса выбери метод и источник: открытые сайты (какие домены), материалы пользователя, расчёт (`data-analysis`), разбор интерфейсов (`ux-review`), интервью или модельные респонденты (`interviews`, только для гипотез).
5. Задай бюджет: число источников на вопрос и примерную стоимость. Дорогие методы (массовое чтение, много персон) отметь — по ним нужно согласие человека.
6. Заполни `outputs/02-research-plan.md` (таблица + «что сознательно не исследуем»). Удали маркер шаблона.
7. Пробелы, которые закрыть нельзя (нет открытых данных), сразу зафиксируй: `strat q add "…" --why "…"`.
8. Покажи план коротко: топ-вопросы, методы, ориентировочная стоимость. Это не ворота: если человек не возражает, переходи дальше.
   `strat stage collect --next "Собрать материалы по R1–Rn (/collect)"`.
