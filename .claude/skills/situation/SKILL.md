# Картина ситуации

1. `strat claim list` — обзор всего, что есть. Сгруппируй утверждения по вопросам плана.
2. **Синтез.** Сформулируй 3–6 главных выводов. Каждый вывод, который ты сделал сам, — это новое утверждение `--type hypothesis` с `--depends` на опорные факты. Не повышай его до факта.
3. **Противоречия.** Найди утверждения, которые противоречат друг другу. Опиши, какому источнику доверяем больше и почему.
4. **Пробелы.** Для каждого неотвеченного вопроса плана опиши: чего не знаем, почему, насколько это опасно для решения, как закрыть (`method/evidence.md`, раздел «Пробелы»).
5. **Аудитория и альтернативы.** Если вопрос продуктовый, набросай сегменты, задачи и альтернативы по `method/jtbd.md` — они понадобятся в вариантах.
6. Заполни `outputs/03-situation.md`: «Коротко» → «Что известно» → «Что мы предполагаем» → «Чего мы не знаем» → «Противоречия». Ссылки [C#] у каждого существенного утверждения и числа. Удали маркер шаблона.
7. `strat validate 03-situation.md` — исправь ошибки.
8. Покажи человеку «Коротко» и главные пробелы. Спроси, нет ли у него данных, которые закроют критичные пробелы. Если есть — `/collect` для них, иначе:
   `strat stage options --next "Сформировать варианты (/options)"`.
