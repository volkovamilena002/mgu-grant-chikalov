# Продолжение работы

1. `python tools/strat.py status --journal 10`. Если активного проекта нет — `strat list` и спроси, какой продолжить (или предложи /kickoff).
2. **Незавершённые шаги.** Для каждого шага из «Незавершённые шаги» проверь, есть ли его результат (файл, источник, утверждения):
   - результат есть → `strat step done <key> --result "восстановлено после перерыва"`;
   - результата нет → выполни шаг заново: `strat step start <key> --force` и дальше по обычной процедуре.

   Никогда не повторяй молча действие, отмеченное как `done`.
3. **Контекст.** Прочитай только нужное: документ текущей стадии в `outputs/` и документ предыдущей стадии. Реестры смотри через `strat claim list` и `strat source list`, а не целиком файлами.
4. **Пересмотр.** Если в статусе есть «Требуют пересмотра», сначала предложи разобрать их (навык `update`).
5. **Напомни человеку** в 3–4 строках: задача, где остановились, что сделано с прошлого раза, следующий шаг. Если следующий шаг — ворота, задай вопрос ворот.
6. Выполни следующий шаг по навыку текущей стадии (он указан в статусе: «→ навык /…»).
